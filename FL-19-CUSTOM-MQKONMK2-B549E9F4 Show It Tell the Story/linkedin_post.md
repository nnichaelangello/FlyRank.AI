# LinkedIn Post Draft (Build in Public)

I just deployed my personal portfolio and Machine Learning capstone as part of the FlyRank AI Internship! 🚀 You can check out the live site here: https://ship-the-ugly-one-lovat.vercel.app/

This track challenged me to build both an AI-native frontend and a robust backend ML pipeline. I want to highlight two things I learned along the way:

1️⃣ **Real Proof > Generative Aesthetics:** When designing the case studies for my past projects (like AKSARA and PRISMA), it was tempting to generate flawless, futuristic AI artwork to represent them. I actively chose *not* to. Instead, I used raw, real screenshots of the actual software I built. A slightly imperfect screenshot of working code tells an employer infinitely more about my capability than a perfectly prompted AI graphic. The design should frame the work, not upstage it.

2️⃣ **Honesty in AI Agents:** I also built a Python "Research Scout Agent" to autonomously scrape web data. While it's incredibly fast, it has a strict limitation: because it relies on standard HTTP requests, it cannot parse client-side rendered JavaScript or bypass heavy Cloudflare protection. Acknowledging these limitations isn't a weakness—it's engineering diligence. (I'm already planning a v2 using Playwright to solve this!).

Massive thanks to the FlyRank team for the framework. I'm excited to keep building!
