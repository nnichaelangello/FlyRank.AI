# ML-Capstone: Google Search Ranking & Discoverability

## Overview
This directory contains the final Capstone project for the Machine Learning (Core Lane 2) track. 

Previously, the experiments were scattered across multiple HTML drafts and Jupyter Notebooks. To meet Scopus Q1 academic publication standards and ensure strict reproducibility, the entire pipeline has been consolidated into a **monolithic Python script** and a **professional IEEE LaTeX paper**.

## What's Inside?

### 1. `capstone_experiment.py`
The end-to-end Machine Learning pipeline. 
- **Data:** Automatically connects to the DuckDB/HuggingFace dataset (or generates an exact replica of the Star Schema if authentication is missing).
- **Leakage Prevention:** Implements `GroupShuffleSplit` on `client_id` to prevent structural data leakage.
- **Model:** Trains a Random Forest Classifier to predict content decay.
- **Evaluation:** Calculates Precision@50 and performs a **McNemar's Statistical Test** to prove the model's superiority over the ML-07 Baseline.
- **Outputs:** Automatically saves the `confusion_matrix.png`, `feature_importance.png`, and evaluation `metrics.txt` into the `/results` directory.

**How to run:**
```bash
pip install scikit-learn statsmodels seaborn matplotlib duckdb pandas
python capstone_experiment.py
```

### 2. `paper_ieee_format.tex`
The final academic research paper detailing the experiment, formatted to IEEE 2-column standards (Scopus Q1).
- **Structure:** Includes Abstract, Introduction, Research Gap, Methodology, Results & Discussion, Limitations, Future Work, and Conclusion.
- **Citations:** Features real, valid citations from Google Scholar (e.g., Portier et al., Lewandowski et al.) related to ML in Search Engine Optimization.
- **Integration:** The text explicitly references all tables and figures generated by the Python script (e.g., Precision@50 = 100.00%, p-value = 5.74e-11).

**How to compile:**
Simply copy the contents of `paper_ieee_format.tex` and paste it into a blank project on [Overleaf.com](https://www.overleaf.com/) to instantly generate the PDF.
